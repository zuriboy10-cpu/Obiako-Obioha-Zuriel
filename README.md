### Objectives

- Display formatted output.
- Compile, test and submit Java programs using GitHub.

### Programs
1. `week03/SimpleCalculator.java` - Performs arithmetic calculations on two numbers.
2. `week03/AverageCalculator.java` - Calculates the total and average of three scores (with score validation).
3. `week03/ItemCost.java` - Calculates the total cost using quantity and unit price.

### How to Run
Open a terminal in the `week03` directory.
- `javac SimpleCalculator.java` then `java SimpleCalculator`
- `javac AverageCalculator.java` then `java AverageCalculator`
- `javac ItemCost.java` then `java ItemCost`
